# 境界値・異常系の分析

共通制約は [AGENTS.md](../../../AGENTS.md)。
変更箇所に関係する境界を選び、期待挙動は戦略仕様・提出契約から決める。

| 条件 | 確認する実害 |
| --- | --- |
| 途中上場・上場廃止・売買停止・再上場 | 履歴の混同、欠損補完による未来参照、必要行の欠落。 |
| 出来高0・極小、High=Low、std=0 | VWAP・流動性・ボラティリティ指標のゼロ除算とInf。 |
| 前場・後場の欠損、半日取引 | 時間帯列の欠損と定義済みfallback。 |
| ローリング窓の開始・fold境界 | min_periods、窓不足、ラベルpurge、未来補完。 |
| PIT公開日・属性更新 | 公開前の利用、最新属性の過去への適用。 |
| 同値多数・銘柄数不足 | 分位分割例外、tie-breakの入力順依存、空ポートフォリオ。 |
| 分割・併合・極端値 | raw水準とreturnの扱い、単一値の支配。 |
| indexの順序変更・重複・不足 | join増殖、alignment、全対象行のcoverage。 |

0埋め・中央値補完・epsilon・clip・`rank(method="first")` は選択肢であり、
分析だけの依頼で自動追加しない。意味が変わる対処は仕様差分として明示する。
予測側のindexは許可された入力から得て、Valid targetを読み込まない。

各ケースについて入力条件、現行挙動、期待挙動、実害、最小の再現例・テスト案を示す。
修正が依頼されている場合は必要な対処と関連回帰まで進める。
