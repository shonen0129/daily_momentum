# 2. Research Basis

## H1

Barardehi, Bogousslavsky, Muravyev,

"What Drives Momentum and Reversal?
Evidence from Day and Night Signals"

Review of Financial Studies, 2026。

同研究では、過去returnをintradayとovernightへ分解すると、

```text
past intraday return
→ future momentum

past overnight return
→ comparable momentum is not observed
```

という非対称性が報告されている。

> 現在のopen-to-open Momentumではintraday informationとovernight componentが混ざっているため、Short側のsignalが弱くなっている可能性がある

というもの。

"Skewness Managed Portfolios"

2026。

同研究は、cross-sectional anomaliesのperformanceが少数の極端なpositive-return stocksに大きく左右されることを示し、

```text
Long:
High expected skewness preferred

Short:
Low expected skewness preferred
```

というportfolio constructionを提案している。

今回の仮説は、

> Champion FD Short自体には弱いShort情報があるが、positive-skew / lottery-like stocksをShortしてしまうことでShort P/Lが毀損している可能性がある

というもの。

# 21. Skewness研究の基本思想

今回、

```text
High skewness -> Short
```

とはしない。

逆。

目的は、

```text
Fundamental的には悪い
しかし
大幅上昇するright-tail riskが高い
```

銘柄をShort portfolioから遠ざけること。

つまり、

```text
Low expected skewness
→ Shortに好ましい

High expected skewness
→ Shortを避ける
```

というportfolio overlayである。

---

# 22. Expected SkewnessはEx-Anteで作る

future realized skewnessをsignalとして直接使用してはいけない。

月 `m+1` に利用するExpected Skewnessは、

```text
month m終了時点までの情報
```

だけから作る。

Expected Skewnessは1か月固定し、月中にfuture情報で更新しない。

これによりsignal自体をslowに保つ。

---

# 23. Monthly Residual Return

Skewness計算には既存の安全な、

```math
ResidualReturn_{i,d}
=
rawReturn_{i,d}
-
beta_{i,d} TOPIXReturn_d
```

を使用する。

未来returnを使用しない。

---

# 24. Realized Skewness

各銘柄・各calendar monthについて、日次Residual Returnから月次Realized Skewnessを作る。

概念：

```math
RS_{i,m}
=
\frac{
mean[(r-\bar r)^3]
}{
std(r)^3
}
```

最低、

```text
15 valid daily observations
```

を要求する。

不足ならmissing。

bias correction等の実装方式はbacktest前に1つへ固定し、全期間で同一にする。

---

# 25. Realized Volatility

```math
RV_{i,m}
=
Std(
ResidualReturn_{i,d},
d \in m
)
```

最低観測数はRealized Skewnessと同じ。

---

# 26. Prior Month Return

```math
PMRet_{i,m}

\sum_{d \in m}
```

# 77. 最終原則

今回の目的は、

> Short Net Sharpeが正になるまで設定を探し続けること

ではない。

目的は、

> **2026年の研究から導かれる2つの異なる経済仮説、
> 「intraday tradingに含まれるinformation continuation」と
> 「positive-skewness stocksをShortするtail risk」を、
> 現ChampionのLong alphaを一切壊さず、
> 日本株1日先residual-return competitionで有限かつ因果的に検証すること**

である。

特にShort側について、

```text
Gross Return
Net Return
Gross Sharpe
Net Sharpe
Turnover
Cost
Right-tail losses
Fold consistency
```

を必ず分解する。

総合Net Sharpeだけで結論を出してはいけない。

作業途中で人間への確認を求めず、公式ルール、AGENTS.md、本指示、既存実装から合理的に判断できる範囲は自律的に処理し、Train-only実装・バックテスト・監査・REPORT作成まで完了してください。
