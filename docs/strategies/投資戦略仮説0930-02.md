# Event-Box × SN1 Cross-Sectional Strategy Hypothesis

## 1. Objective

本研究の目的は、**Event-driven Boxで捉えた価格構造が、既存のSN1_H1に対して翌営業日のクロスセクショナル順位予測に追加情報を持つか**を検証することである。

コンペでは各営業日に全銘柄へ連続スコアを付与し、そのクロスセクショナル順位を5分位に分割する。

- Q1 / Q2: Short
- Q3: Neutral
- Q4 / Q5: Long

したがって、本戦略は個別銘柄に対して直接「買い・売り」を決定するものではない。

予測対象は、

\[
S_{i,t}
=
\text{銘柄 }i\text{ の翌営業日における相対的な強さ}
\]

であり、Event Boxはこの相対順位を改善するための特徴量として使用する。


## 2. Background

既存のSN1_H1では、High breakoutとLow breakoutを別の情報源として扱い、方向別に状態を保持する設計を採用している。

過去の開発データでは、

- Long側が主な正の収益源
- Short側はTrain・historical Validの双方でNet-negative
- 長期間継続したLong membershipがLong利益の大部分を占める
- High/Low状態を単純に加算するより、sourceを分離して扱うことでturnover/costが低下する可能性

が観測された。

一方、直近のEvent Box実験では、固定仕様のBox内Mean Reversionは継続条件を満たさなかった。

MR episodeでは、TP-first率は29.23%、ドリフトなしのfirst-passage基準 \(p_0\) は29.71%であり、

\[
p-p_0=-0.475\text{ pp}
\]

だった。ネット平均episode returnも負であった。

また、MR entryのグロス損失はLongよりShort側に集中していた。

- Long gross contribution: -0.80%
- Short gross contribution: -9.33%



したがって、Box内の上端を機械的にShortする対称的なMean Reversionは採用しない。


## 3. Core Hypothesis

中心仮説は次の通りである。

> **Event Boxによって識別された上方向・下方向の価格構造は、SN1_H1が持つクロスセクショナル相対強度情報に対して追加的な順位予測情報を持つ。**

ただし、上方向と下方向は対称とは仮定しない。

特に、

> **上方breakout後に価格構造が維持されている銘柄、およびその上昇構造内で押し目を形成している銘柄は、翌営業日のクロスセクショナル順位が相対的に高くなる可能性がある。**

一方、

> **下方breakoutは銘柄の相対的弱さを示す情報になり得るが、それ自体を独立したShort alphaとは仮定しない。**

したがって、

\[
\text{Up Breakout}
\neq
-\text{Down Breakout}
\]

として扱う。


## 4. Role of Event Box

Event Boxは売買ルールではなく、各銘柄の**市場構造を記述する状態変数**として使用する。

主な構造状態は以下とする。

- `BOX`
- `UP_STRUCTURE`
- `DOWN_STRUCTURE`
- `SEARCH / FORMING`

上方breakout発生後は `UP_STRUCTURE` を開始し、新しいBoxが形成されても上方向構造が明確に失敗するまで状態を保持する。

つまり、

\[
\text{Breakout Event}
\rightarrow
\text{Persistent Structural State}
\]

とする。

これにより、SN1で観測されたLong membershipの持続性を、単なるEWMA減衰ではなく価格構造によって表現する。


## 5. Event-Box Features

各銘柄・各営業日について、少なくとも以下の特徴量を生成する。

### 5.1 Directional state

\[
UPSTATE_{i,t}
\]

\[
DOWNSTATE_{i,t}
\]

上方向・下方向の構造を別々に保持する。


### 5.2 Breakout strength

上方向：

\[
BO^{UP}_{i,t}
=
\frac{C_{i,t}-H_{i,t}}
{ATR_{i,t-1}}
\]

下方向：

\[
BO^{DOWN}_{i,t}
=
\frac{L_{i,t}-C_{i,t}}
{ATR_{i,t-1}}
\]

正規化座標 \(x\) はbreakout判定には使用しない。


### 5.3 Box geometry

\[
WidthATR_{i,t}
=
\frac{H_{i,t}-L_{i,t}}
{ATR_{i,t-1}}
\]

加えて、

- Box確定後の経過時間
- structure age
- breakoutからの経過時間
- breakout failure flag

を保持する。


### 5.4 Box position

確定済みBoxについて、

\[
x_{i,t}
=
2\frac{C_{i,t}-L_{i,t}}
{H_{i,t}-L_{i,t}}
-1
\]

を計算する。

ただし \(x\) 単独ではLong/Short方向を決定しない。


## 6. Trend-Aligned Pullback Hypothesis

棄却されたMean Reversionを、そのまま再導入しない。

代わりに、上昇構造がすでに存在するときのBox内位置を**押し目特徴量**として利用する。

例えば、

\[
Pullback^{UP}_{i,t}
=
UPSTATE_{i,t}
\cdot
\max(0,-x_{i,t})
\]

とする。

これは、

- 単なるBox下端への下落
- 上方breakout後の継続構造内での押し目

を区別する。

仮説は、

\[
E[r^{rel}_{i,t+1}
\mid
UPSTATE=1,\ x<0]
>
E[r^{rel}_{i,t+1}
\mid
UPSTATE=0,\ x<0]
\]

である。

つまり、Box下端そのものにMean Reversion edgeがあるのではなく、

> **上方向の親構造を持つ銘柄の押し目に相対的な継続edgeが存在する**

可能性を検証する。


## 7. No Symmetric MR Short Hypothesis

初期候補では、

\[
x>0
\Rightarrow Short
\]

というルール、および

\[
DOWNSTATE\times x
\]

を上方向の完全対称として導入しない。

理由は、

1. 固定Box MRのShort側が大きな負寄与だったこと
2. SN1系の既存診断でもShort側が安定した正のNet contributionを示していないこと

である。

Down structureは、

\[
\text{absolute Short signal}
\]

ではなく、

\[
\text{cross-sectional weakness information}
\]

としてモデルへ入力する。


## 8. Score Architecture

最終的に各銘柄へ1つの連続スコアを出力する。

概念的には、

\[
S_{i,t}
=
f(
SN1_{i,t},
UPSTATE_{i,t},
DOWNSTATE_{i,t},
BO^{UP}_{i,t},
BO^{DOWN}_{i,t},
WidthATR_{i,t},
BoxAge_{i,t},
Failure_{i,t},
Pullback^{UP}_{i,t},
RS60_{i,t}
)
\]

とする。

ただし、手動で特徴量に重みを付けない。

既存SN1の研究フレームと同様に、過去データだけを用いたyearly expanding Ridgeによって翌営業日のクロスセクショナル残差順位を推定する。

初期実験では正則化パラメータ等を新たに探索せず、既存SN1_H1と可能な限り同一条件を維持する。


## 9. Why Keep SN1 as the Dense Baseline

Event Boxはイベント駆動であるため、そのままスコア化すると多数の銘柄で同一値またはゼロが発生しやすい。

コンペのポートフォリオはスコア順位によって決まるため、スコアの大量tieは望ましくない。

したがって、

\[
\boxed{
\text{Dense SN1 baseline}
+
\text{Event Box structural information}
}
\]

という構成にする。

Event Boxのみで日次全銘柄を順位付けすることは初期仮説としない。


## 10. Candidate Design

大量のパラメータ・interaction探索は行わず、初期検証は以下の固定候補に限定する。


### Baseline: SN1_H1

現在のSN1_H1を完全再現する。

これは全ての比較の基準とする。


### Candidate A: SN1 + Event Box Structure

SN1_H1にEvent Boxの構造特徴量だけを追加する。

主な追加情報：

- UP / DOWN structure
- breakout strength
- box width / ATR
- structure age
- box age
- breakout failure

仮説：

> Event Boxによる状態表現はSN1_H1に対して追加的なcross-sectional ranking informationを持つ。


### Candidate B: Candidate A + Uptrend Pullback

Candidate Aに、

\[
Pullback^{UP}
=
UPSTATE\cdot\max(0,-x)
\]

を1つ追加する。

仮説：

> 上方breakout後に構造が維持されている銘柄では、Box下側への押しが翌営業日の相対的な強さに結びつく。

これは従来のMean Reversion仮説ではなく、

\[
\boxed{
Trend\ Continuation
+
Pullback
}
\]

仮説である。


## 11. Competition Portfolio Mapping

モデルは毎営業日・全銘柄について1つのスコアを返す。

\[
S_{i,t}\in\mathbb{R}
\]

公式評価器が日次クロスセクションで5分位に分割し、

\[
Q1,Q2
\rightarrow Short
\]

\[
Q3
\rightarrow Neutral
\]

\[
Q4,Q5
\rightarrow Long
\]

へ変換する。

したがって本研究では、Long銘柄・Short銘柄を直接選択しない。


## 12. Primary Evaluation Metrics

Event Box BOの先行実験では、Donchian比でturnoverとcostは改善したが、Gross performanceの改善は確認されなかった。

したがって新仮説では、Net Sharpeだけでなく、

1. Gross annual return
2. Gross Sharpe
3. RankIC
4. Q5 − Q1 spread
5. quintile monotonicity
6. Long contribution
7. Short contribution
8. turnover
9. transaction cost
10. Net Sharpe

を分解して評価する。

特に、

\[
\Delta Gross > 0
\]

がEvent Boxによる情報追加の主要な判断材料となる。

turnover低下だけによるNet改善は、ranking alpha改善とは区別する。


## 13. Attribution Tests

Candidate A / Bについて、少なくとも以下を分解する。

### Direction

- UP structure
- DOWN structure
- no structure


### Position inside Box

- lower region
- center
- upper region


### Parent direction × Box position

特に、

\[
UPSTATE=1,\quad x<0
\]

を独立bucketとして確認する。


### Long / Short portfolio side

Event Box特徴量による改善が、

- Longの改善
- Shortの改善
- turnover reduction

のどこから生じたかを分離する。


## 14. Rejection Criteria

以下の場合、Event Box拡張は棄却する。

### Candidate A

Event Box構造を追加しても、

- Gross return
- RankIC
- Q5−Q1
- quintile monotonicity

に追加的改善がなく、Net改善が主としてturnover/cost削減だけから生じる場合。


### Candidate B

Trend-aligned Pullbackを追加しても、

\[
UPSTATE=1,\ x<0
\]

のbucketに正の追加情報がなく、Candidate Aに対するGrossまたはranking改善が確認できない場合。


### General

特定年、特定銘柄群、特定parameter一点だけで改善し、近隣仕様・期間で符号が反転する場合は採用しない。


## 15. What This Hypothesis Does Not Claim

本仮説は以下を前提としない。

- Box内価格には一般的なMean Reversion edgeがある
- 下方breakoutをShortすれば利益になる
- UP/DOWNは完全に対称である
- Event BoxそのものがSN1より優れたalphaである
- state persistenceが長いほど必ず収益性が高い
- historical development dataでの改善が将来も再現する

検証対象はあくまで、

\[
\boxed{
\text{Event Box構造がSN1_H1のcross-sectional rankingを追加的に改善するか}
}
\]

である。


## 16. Research Sequence

検証順序を以下に固定する。

\[
\boxed{
SN1\_H1
\rightarrow
Candidate\ A
\rightarrow
Candidate\ B
}
\]

Candidate Aが追加情報を示さなければCandidate Bを高度化しない。

Candidate Bまで成功した場合にのみ、

- volume
- retest
- Box hazard
- additional interaction
- nonlinear model

等を将来の別仮説として検討する。


## 17. Summary

本戦略は、

\[
\boxed{
\text{SN1のCross-Sectional Momentum}
+
\text{Event BoxのStructural Persistence}
+
\text{Uptrend Pullback}
}
\]

を統合したランキング戦略である。

Event Boxの役割はLong/Shortを直接決定することではなく、

> **価格がどちらの方向の構造にあり、その構造の中で現在どこに位置するか**

をSN1のクロスセクショナル予測へ追加することである。

特に、棄却された対称的なBox Mean Reversionを、

\[
\boxed{
\text{Trend-independent MR}
\rightarrow
\text{Trend-aligned Pullback}
}
\]

へ置き換えることが、本仮説の中心的な変更点である。
