# 新規投資戦略案

## Asymmetric Momentum Long / Fundamental Short Strategy

---

# 1. 戦略概要

本戦略では、Long側とShort側を同一のalpha軸の両端として扱わない。

基本思想は、

> **Longは中期Residual Momentumで選び、ShortはFundamental Deteriorationと価格弱含みの組み合わせで選ぶ。Liquidity / Volume / Price ImpactはShortの方向を作るのではなく、その下落を信用してよいか判定する補助情報として利用する。**

ことである。

基本構造は、

```math
LongAlpha
=
Momentum
```

```math
ShortBase
=
FundamentalDeterioration
\times
WeakPrice
```

```math
ShortRisk
=
ShortBase
\times
ShortConfirmation
```

```math
FinalScore
=
LongAlpha
-
\lambda ShortRisk
```

とする。

---

# 2. 背景

前回のTrain-only研究では、

* 60日市場Residual Momentum
* 直近1観測行skip
* EWMA alpha = 0.25

の単純なMomentumモデルが、複雑なLiquidity / Microstructureモデルよりも安定していた。

一方で、MomentumモデルのLong側とShort側には非対称性が見られた。

Long側には一定の正の寄与がある一方、

> **Negative Momentum銘柄をそのままShortするロジックは弱い**

可能性が示された。

また、

* Liquidity Vacuum
* Volume Confirmation
* PWV / VWP
* Intraday Reversal

をMomentum correctionとして利用する案については、一貫したNet Sharpe改善が確認できなかった。

そこで次戦略では、

> Momentumをさらに複雑化する

のではなく、

> **Long側の比較的有効だった構造を残し、弱かったShort側だけを別alphaへ置き換える**

ことを目的とする。

---

# 3. 戦略仮説

本戦略の中心仮説は、

```math
LongAlpha \neq -ShortAlpha
```

である。

株価が上がっている銘柄をLongする理由と、

株価が下がっている銘柄をShortする理由は、

必ずしも同一である必要はない。

Longでは、

> 相対的に強い価格トレンドのContinuation

を狙う。

Shortでは、

> **Fundamentalが悪化しており、それを市場価格も下方向へ確認している銘柄の継続的なUnderperformance**

を狙う。

---

# 4. Long側の基本設計

## 4.1 Longのコア

Long側は原則としてシンプルに、

```math
\boxed{
LongAlpha = 60日市場Residual Momentum
}
```

とする。

市場Residual Return：

```math
ResidualReturn_{i,t}
=
rawReturn_{i,t}
-
\beta_{i,t}TOPIXReturn_t
```

Momentum：

```math
M60_{i,t}
=
\sum_{k=1}^{60}
ResidualReturn_{i,t-k}
```

を基本とする。

実装上は、

* 60観測営業日
* 直近1観測行をskip
* 履歴不足はneutral
* 長期欠測・code再登場時は履歴reset

を基本とする。

---

# 5. Long側Cross-Sectional Score

Momentumを日次クロスセクションで順位化する。

例：

```math
L
=
2\times PercentileRank(M60)-1
```

これにより、

```text
-1 : Momentum最弱
 0 : 中立
+1 : Momentum最強
```

程度のスケールにする。

ただしLongAlphaとして利用するのは主に正方向の情報であり、

> 負のMomentumをそのままShort alphaとはみなさない。

---

# 6. Long側Score Persistence

Momentumのturnoverを抑制するため、EWMAを利用する。

第一候補：

```math
L_t
=
0.25L^{new}_t
+
0.75L_{t-1}
```

前回研究結果との連続性から `alpha=0.25` を基準とする。

必要な場合のみTrain-onlyで、

```text
0.15
0.25
0.35
```

程度の少数候補を比較する。

---

# 7. Long側へのLiquidity利用

Liquidity Shock等は、Long alphaの主役にはしない。

基本モデルは、

```math
LongAlpha=M60
```

を維持する。

ただし追加研究として、

> **Momentum winnerの中で、価格形成の確認材料としてLiquidity情報が使えるか**

を少数候補のみ検証してよい。

---

## 7.1 Positive Liquidity Confirmation

例えば、

```math
PositiveLS
=
\max(LiquidityShock,0)
```

として、

```math
L_{liq}
=
Rank(M60)
\times
PositiveLS
```

を作る。

最終Long候補：

```math
LongAlpha
=
Rank(M60)
+
\gamma L_{liq}
```

---

## 7.2 重要な制約

Liquidity悪化を理由にMomentum Longを機械的に弱めない。

つまり、

```math
LiquidityShock < 0
\Rightarrow
Longを削減
```

という単純Gateは基本候補としない。

Liquidityは、

> Momentumを止める情報

ではなく、

> **Momentumを追加的に確認できる場合だけ小さく強化する情報**

として検証する。

改善が安定しなければ、Long側はMomentum-onlyに戻す。

---

# 8. Short側の基本設計

Short側は単純なNegative Momentumを使用しない。

第一候補は、

```math
\boxed{
ShortBase
=
FundamentalDeterioration
\times
WeakPrice
}
```

とする。

意味：

> Fundamentalが悪化しており、さらに市場価格も下方向へ動いている企業だけを強いShort候補とする。

---

# 9. Fundamental Deterioration

Fundamental Shortでは、単なる低水準より、

> **悪化方向**

を重視する。

中心候補：

* CFO / Assets
* CFO / Assets YoY Change
* Net Cash / Balance Sheet Fragility

---

# 10. CFO / Assets

営業キャッシュフローの収益性を見る。

```math
CFOAssets
=
CFO / TotalAssets
```

低いほどFundamental weaknessが強い。

```math
CFOWeakness
=
Rank(-CFOAssets)
```

---

# 11. CFO / Assets YoY Deterioration

Short側の第一候補特徴量。

```math
CFOYoYDelta
=
CFOAssets_t
-
CFOAssets_{previous\ comparable\ period}
```

悪化方向を、

```math
CFODeterioration
=
Rank(-CFOYoYDelta)
```

とする。

高いほど、

> 前年同期と比べて営業キャッシュフロー収益性が悪化している

ことを意味する。

---

# 12. Balance Sheet Fragility

候補としてNet Cash Proxyを利用する。

例えば、

```math
NetCashProxy
=
(Cash-LiabilitiesProxy)/Assets
```

とし、

```math
Fragility
=
Rank(-NetCashProxy)
```

とする。

Net Cashが少なく負債負担が大きい企業ほどShortRiskを高くする。

---

# 13. Fundamental Deterioration Composite

基本候補：

```math
FD
=
w_1 CFODeterioration
+
w_2 CFOWeakness
+
w_3 Fragility
```

第一候補の固定重み例：

```math
FD
=
0.5 CFODeterioration
+
0.3 CFOWeakness
+
0.2 Fragility
```

ただしこれは初期仮説であり、重みを細かく最適化しない。

比較は、

```text
Equal Weight
Deterioration-heavy Weight
```

程度に制限する。

---

# 14. Weak Price Confirmation

Fundamentalが悪いだけでは、

> 悪材料がすでに価格へ織り込まれている

可能性がある。

そこで価格側の確認として、

```math
WeakPrice
=
Rank(-M60)
```

を利用する。

高いほど市場Residual Momentumが弱い。

---

# 15. Short Base Model

第一候補：

```math
\boxed{
S_0
=
FD
\times
WeakPrice
}
```

とする。

つまり、

> **Fundamental悪化だけでも、Negative MomentumだけでもShortしない。両方が確認された銘柄を優先する。**

---

# 16. なぜNegative Momentum単独をShortにしないか

Momentum-onlyでは、

```text
強いMomentum → Long
弱いMomentum → Short
```

となる。

しかし今回の戦略では、

```text
強いMomentum → Long候補
弱いMomentum → Short候補とは限らない
```

と考える。

Negative Momentum銘柄には、

* 一時的に売られすぎた銘柄
* Liquidity Vacuumで価格だけ落ちた銘柄
* Fundamentalに問題のない短期下落銘柄

も含まれる。

そのため、

```math
NegativeMomentum
```

はShort alphaではなく、

> Fundamental deteriorationを価格面から確認するための条件

として使う。

---

# 17. Liquidity / Price ImpactのShort側利用

LiquidityやPrice Impactは、

> Shortを生成する独立alpha

ではなく、

> **その下落を信用してShortしてよいか判定するフィルター**

として使う。

中心となる考え方は、

```math
ShortRisk
=
ShortBase
\times
ShortQuality
```

である。

---

# 18. Liquidity Vacuum Avoidance

Fundamentalが悪く価格も下落していても、

> 流動性が枯れた状態で少量の注文によって価格だけ大きく落ちた

可能性がある。

その場合、

> 安値でShortしてReversalを受ける

危険がある。

したがって、

```math
LiquidityVacuum
=
PWV
\times
NegativeLiquidityShock
```

をShort回避情報として利用する。

---

# 19. Short Model S1 — Vacuum Filter

基本Short：

```math
S_0
=
FD\times WeakPrice
```

Liquidity Vacuumを使った候補：

```math
S_1
=
S_0
\times
(1-\gamma VacuumScore)
```

ここで、

```math
VacuumScore\in[0,1]
```

とする。

意味：

> Fundamentalも価格も弱いが、下落がLiquidity Vacuum的ならShort確信度を下げる。

---

# 20. Liquidity Shock

Liquidity LevelとShockは分離する。

Baseline：

```math
LiquidityLevel
=
\log(MedianTradingValue_{60}+\epsilon)
```

Shock：

```math
LiquidityShock
=
\log
\frac{
MedianTradingValue_5+\epsilon
}{
MedianTradingValue_{60}+\epsilon
}
```

Short Filterでは、

```math
LiquidityShock<0
```

だけでShortを作らない。

必ず、

```text
Price Impact
Fundamental Deterioration
Weak Price
```

との組み合わせで使用する。

---

# 21. Expected Price Impact

通常ならその取引環境でどれだけ価格が動くかを推定する。

```math
ExpectedMove
=
f(
VolumeShock,
BaselineLiquidity,
Volatility,
Size
)
```

残差：

```math
ImpactResidual
=
ObservedMove
-
ExpectedMove
```

---

# 22. PWV / VWP

```math
PWV
=
max(ImpactResidual,0)
```

```math
VWP
=
max(-ImpactResidual,0)
```

とする。

Short側では特に、

```text
Down move
PWV high
Liquidity Shock negative
```

の組み合わせを、

> 下落が流動性枯渇によって増幅された可能性

として扱う。

その場合ShortRiskを弱める候補とする。

---

# 23. Sell Participation Confirmation

逆に、

> 多くの市場参加を伴ってFundamental悪化銘柄が売られている

場合はShortを強化できる可能性がある。

候補条件：

```text
Residual Return negative
Volume Shock positive
Liquidity not severely deteriorating
Price Impact not abnormally large
```

これを、

```math
SellParticipation
```

として定義する。

---

# 24. Short Model S2 — Sell Participation Boost

```math
S_2
=
S_1
\times
(1+\delta SellParticipation)
```

意味：

> Fundamental悪化 + Price weaknessに加え、通常の流動性環境で十分な売買参加を伴った下落ならShort確信度を高める。

ただしVolume Confirmation単独では使用しない。


# 43. Fundamental Freshness

古すぎる財務値を無期限に利用しない。

既存の安全な財務feature builderが存在する場合は、そのPoint-in-Time処理・freshness処理を第一候補として再利用する。

新しいfreshness期間を無制限に探索しない。

# 44. Missing Fundamental Data

Missingを自動的にShort扱いしない。

原則：

```text

```

または当日Cross-Sectional median。

Missing indicatorを使う場合も、経済的仮説を明確化してから検証する。

# 59. 戦略の最終思想

Long側：

```math
\boxed{
Long
=
Persistent Residual Momentum
}
```

Short側：

```math
\boxed{
Short
=
Fundamental Deterioration
\times
Weak Price
}
```

Short Filter：

```math
\boxed{
Liquidity / PriceImpact
=
Is\ this\ decline\ trustworthy?
}
```

つまり、

> **Liquidityは「下がったからShort」の根拠には使わない。Fundamentalが悪化して価格も弱い銘柄について、その下落が本物の継続的な売りなのか、一時的なLiquidity Vacuumなのかを判定するために使う。**

LongとShortを同一因子の上下として扱わず、

```text
Long  = Price Trend
Short = Fundamental Deterioration + Price Confirmation
```

と役割を分ける。

本戦略の目標は、

> **既存MomentumのLong側の強みを維持しながら、弱かったShort側をFundamentalベースの持続的なalphaへ置き換え、必要な場合のみLiquidity / Price ImpactでShortの質を改善すること**

である。
