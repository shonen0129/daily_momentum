# イベント駆動型ボックス戦略：統合仕様・検証方針

## 1. 戦略の基本仮説

本戦略は、相場を次の2種類の価格形成メカニズムに分ける。

1. **確定したボックス内**
   - 価格は一定程度平均回帰する可能性がある
   - 下端付近ではロング、上端付近ではショートを検討する

2. **ボックスを明確に突破した後**
   - 平均回帰仮説を停止する
   - ブレイク方向へのモメンタムを利用する
   - 旧ボックスは終了し、新しい価格構造の形成を開始する

したがって戦略の本質は、

\[
\boxed{
\text{価格位置}
+
\text{市場構造}
+
\text{状態遷移}
}
\]

である。

ただし、箱内で価格が反発しているように見えるだけでは平均回帰のエッジとは言えない。

ランダムウォークでも、上下の境界に挟まれた価格は中央へ戻る局面を自然に作る。

したがって、

> 「箱があるからMRをする」

ではなく、

> 「同じ箱形成アルゴリズムをランダムな価格系列に適用した場合より、実市場でMRのネット期待値が有意に高いか」

を最初に検証する。


# 2. 状態を「市場構造」と「ポジション」に分離する

従来の

\[
BOX
\rightarrow
BREAKOUT
\rightarrow
FORMING
\rightarrow
NEW\ BOX
\]

という1本の状態変数では、ブレイクポジションを保有しながら新しい箱を形成するケースを表現しにくい。

そこで2軸に分ける。


## 2.1 市場構造状態

### SEARCH

有効なボックスが存在しない状態。

初期起動時、形成失敗後、ブレイク失敗後などに入る。


### EXTEND

上方または下方へのブレイク後、新しい極値を更新している状態。

上方なら高値候補、

\[
H^{cand}
\]

を更新し続ける。


### ANCHOR

ブレイク方向の極値が確定し、反対側の境界を形成している状態。


### BOX

上下両境界が確定し、有効なレンジとして利用できる状態。


したがって構造遷移は、

\[
\boxed{
SEARCH
\rightarrow
BOX
\rightarrow
EXTEND
\rightarrow
ANCHOR
\rightarrow
BOX
}
\]

を基本とする。


## 2.2 ポジション状態

市場構造とは独立して、

\[
p_t
\in
\{
FLAT,\,
MR\_LONG,\,
MR\_SHORT,\,
BO\_LONG,\,
BO\_SHORT
\}
\]

を管理する。

初期実装では、MRとBOの同時保有は認めない。

複雑な重ね持ちや連続ウェイト化は、各脚に独立したエッジが確認されてから検討する。


# 3. ボックス内価格位置

確定済みボックスの上限を \(H\)、下限を \(L\)、終値を \(C_t\) とする。

\[
x_t
=
2\frac{C_t-L}{H-L}-1
\]

と定義する。

これにより、

\[
x=-1
\]

が下限、

\[
x=0
\]

が中央、

\[
x=1
\]

が上限となる。

ただし、**\(x\) はあくまで箱内の相対位置を測るために使用する。**

ブレイク判定には使用しない。


# 4. ブレイクはATR単位で判定する

\[
x>1+\delta
\]

という判定と、

\[
C>H+kATR
\]

という判定は同じではない。

箱幅を

\[
W=\frac{H-L}{ATR}
\]

とすると、

\[
x=1+\frac{2k}{W}
\]

だからである。

固定 \(\delta\) では、

- 狭い箱 → ATR換算のバッファが小さすぎる
- 広い箱 → バッファが大きすぎる

という問題が起きる。

したがって、ブレイクは統一して、

\[
C_t>H+k_{BO}ATR_{t-1}
\]

または

\[
C_t<L-k_{BO}ATR_{t-1}
\]

で判定する。

ATRはブレイク当日の大きな値動きによる自己参照を避けるため、

\[
ATR_{t-1}
\]

または箱確定時に固定したATRを使用する。


# 5. MR損切りとBOエントリーを分離する

MRの損切りとBO開始を同じ閾値にすると、

MRショート → 損切り → BOロング

という全量ドテンがそのまま残る。

そこで、

\[
k_{SL}<k_{BO}
\]

とする。

上方の場合、

\[
C_t>H+k_{SL}ATR
\]

でMRショートを退出。

しかし、

\[
C_t\le H+k_{BO}ATR
\]

ならBOロングには入らない。

つまり、

\[
H+k_{SL}ATR
<
C_t
\le
H+k_{BO}ATR
\]

に**ノーポジション帯**を設ける。

これにより、

\[
MR
\rightarrow
FLAT
\rightarrow
BO
\]

という遷移が可能になる。

大きなギャップによって両閾値を同時に超える場合については、

- 同じ翌寄付きで反転
- 一度FLATにして次の判定を待つ

を別戦略として比較する。


# 6. 新しい箱の形成

上方ブレイクを例にする。


## 6.1 EXTEND

上方ブレイク後、

\[
H^{cand}_t
=
\max(H^{cand}_{t-1},High_t)
\]

として高値候補を更新する。


## 6.2 極値の確定

「3営業日高値更新なし」だけでは、イベント駆動という思想とやや不整合であり、ボラティリティ局面によって意味も変わる。

より自然なのは、

\[
H^{cand}-C_t
\ge
m\,ATR_{t-1}
\]

のように、極値から一定のATR幅だけ反転した時点で上限候補を固定する方法である。

3営業日ルールを残す場合も、

- 最低日数
- ATR反転幅

の両方を満たす形を比較する。


## 6.3 ANCHOR

上限候補確定後、押し安値を追跡する。

反対側の極値が確定し、必要な幅条件を満たした時点で、

\[
(H,L)
\]

を新しいBOXとして確定する。


## 6.4 タイムアウト

一定期間経過しても箱が形成できなければ、無理に箱を作らない。

\[
T>T_{\max}
\]

なら候補を破棄してSEARCHへ戻す。

固定期間Donchianを強制的に箱として採用するより、

> 「箱がないため取引しない」

という状態を認める方が、モデルの意味が明確である。


# 7. ブレイク失敗

上方ブレイク後、

\[
C_t
<
H_{old}
-
k_{fail}ATR_{t-1}
\]

となった場合、BOロングを手仕舞う。

初期版では、

\[
SEARCH
\]

へ戻して旧ボックスを復活させない。

一度明確に破られた箱を再利用すると、状態定義が複雑になるためである。

将来的には、

- 旧箱復活
- Failed Breakout後の逆張り

を独立仮説として比較できる。


# 8. BOX確定時のBOとMR

新しい箱が確定した瞬間、まだBOポジションを保有している可能性がある。

ここは仕様として固定する必要がある。

初期版では最も単純に、

> **新BOX確定時にBOポジションを手仕舞いし、その後MRへ移行する**

とする。

ただし同じ方向に、

BOロング退出 → MRロング開始

となる場合は、実取引では差分だけ売買する。

損益帰属上はBOとMRを分離して記録する。

将来的には、

- BOを継続しMRを停止
- 親トレンド方向のMRだけ許可

も比較対象にする。


# 9. MR戦略

BOX状態でのみ有効とする。

ただし、

\[
x<0 \Rightarrow Long
\]

\[
x>0 \Rightarrow Short
\]

という単純な全域逆張りは使用しない。


## 9.1 エントリー

ロングなら、

\[
x<x_{entry}^{L}
\]

ショートなら、

\[
x>x_{entry}^{S}
\]

という端のゾーンでのみ候補とする。

ただしゾーンの閾値は、最終的には固定値ではなく**期待値から推定する**。


## 9.2 MRの帰無期待値

エントリーを \(x_0\)、利確を \(x_{TP}\)、損切りを \(x_{SL}\) とする。

ドリフトのないランダムウォークでは、TPへ先に到達する確率は

\[
p_0
=
\frac{x_0-x_{SL}}
{x_{TP}-x_{SL}}
\]

となる。

例えば、

\[
x_0=-0.8,\quad
x_{TP}=0,\quad
x_{SL}=-1.2
\]

なら、

\[
p_0
=
\frac{0.4}{1.2}
=
33.3\%
\]

である。

したがって、勝率40%だから優位性があるとは言えない。

比較すべきは50%ではなく、

\[
p-p_0
\]

である。


## 9.3 コストを含めた必要勝率

往復コストを \(x\) 単位で \(c_x\) とすると、

\[
EV
=
p(x_{TP}-x_0)
-
(1-p)(x_0-x_{SL})
-
c_x
\]

なので、

\[
p
>
p_0
+
\frac{c_x}
{x_{TP}-x_{SL}}
\]

が必要になる。

これにより、

- 中央のノートレード帯
- 端でのMR許可範囲
- 最小ボックス幅

をデータから導出できる。


# 10. 箱幅

狭すぎる箱では、

\[
\frac{\partial x}{\partial C}
=
\frac{2}{H-L}
\]

が大きくなり、わずかな価格変化で \(x\) が大きく動く。

またコストの相対負担も大きくなる。

したがって、

\[
W_t
=
\frac{H-L}{ATR}
\]

を必ず使用し、

\[
W_{\min}
<
W_t
<
W_{\max}
\]

を満たす箱だけMR対象とする。

ただし最適な幅を直接Sharpe最大化で選ぶのではなく、MRのネット期待値が正になる領域から決める。


# 11. Box Scoreは初期版では使わない

期間、タッチ数、滞在率、Efficiency Ratio、幅/ATRなどを合成したBox Scoreは魅力的だが、自由度が非常に大きい。

また、

- 形成期間の滞在率は定義上ほぼ100%
- タッチ数が多いほど箱が強いとは限らない
- 長寿命の箱ほどMRが強いとも限らない
- タッチ数・期間・滞在率は互いに相関する

という問題がある。

したがって初期版は、

1. 箱幅が適切
2. 必要なら両側へのタッチあり
3. 必要ならEfficiency Ratio等の単純な二値フィルター

程度に抑える。

MRとBOに独立したエッジが確認された後で初めて、

\[
P(\text{MR成功}\mid X_t)
\]

または、

\[
P(\text{今後 }d\text{ 日以内に箱が破れる}\mid X_t)
\]

を直接予測するモデルへ拡張する。


# 12. BO戦略

BOX状態から、

\[
C_t>H+k_{BO}ATR_{t-1}
\]

ならBO_LONG、

\[
C_t<L-k_{BO}ATR_{t-1}
\]

ならBO_SHORT候補とする。

ただし株式ではロング・ショートは非対称に扱う。

初期版では、

- 上方BO：新規ロング
- 下方BO：既存ロング退出のみ

というロング主体の戦略から始めてもよい。


## 12.1 執行

終値でシグナル判定、

\[
t+1
\]

の寄付きで約定する。

したがって検証リターンも、

\[
O_{t+1}
\]

から測る。

終値から翌終値までのリターンを使うと、注文前のギャップを利益として含めてしまう。


## 12.2 ギャップ

ブレイク後の翌寄付きが大きく乖離する場合、リスクリワードは大きく変わる。

したがって、

- ギャップ幅
- 翌寄りの実約定価格
- ブレイク時のスリッページ

を明示的にモデル化する。

「寄付きが高すぎたら取引をキャンセル」するルールを使う場合、寄付き価格を観測してから同じ寄付き価格で約定したことにはしない。


# 13. ポジションサイズ

単純な

\[
\frac{\sigma^*}{\hat{\sigma}}
\]

型のボラターゲットをMRに使うのは避ける。

狭く静かな箱ほどポジションが大きくなり、その直後のボラ拡大で最大損失を受けやすいためである。

各トレードのサイズは、

\[
N
=
\frac{R_{\text{budget}}}
{
|P_{\text{entry}}-P_{\text{stop}}|
+
g\,ATR
}
\]

とする。

ここで、

- \(R_{\text{budget}}\)：1トレード当たり損失予算
- \(gATR\)：ギャップ・スリッページ余裕

である。

さらに、

- 1銘柄最大サイズ
- 総グロス
- 総ネット
- セクター上限
- 同時ブレイク時の全体リスク

を制限する。

BOとMRは損益分布が異なるため、別々のリスク予算を持たせる。


# 14. 検証単位は「日」ではなく「エピソード」

単純な、

\[
E[r_{t+1}\mid x_t]
\]

だけでは不十分である。

MRの経済的な1単位は、

\[
\text{Entry}
\rightarrow
\text{TP / SL / Time-out}
\]

である。

BOは、

\[
\text{Breakout}
\rightarrow
\text{Failure / Trail Exit}
\]

である。

したがって主な分析単位をエピソードとする。


## MRエピソード

- ネット期待値
- TP先着率
- \(p-p_0\)
- MAE
- MFE
- 保有期間
- コスト
- タイムアウト率


## BOエピソード

- ブレイク後累積超過リターン
- 失敗率
- MAE
- MFE
- トレール終了までの期待値
- ギャップ
- スリッページ


# 15. 損益を「箱ライフサイクル」でも集計する

単純な4脚、

1. MRロング
2. MRショート
3. BOロング
4. BOショート

だけでは不十分である。

この戦略で最も危険なのは、

1. 上限でMRショート
2. ブレイクしてMR損切り
3. BOロング
4. ダマシでBOも損切り

という二重損失である。

そこで各取引を元の箱IDに紐づけ、

\[
PnL_{\text{box}}
=
PnL_{MR}
+
PnL_{BO}
-
Costs
\]

を計算する。

特に、

\[
P(
BO\text{でも損失}
\mid
MR\text{で損失}
)
\]

と、

「MRを追加したことでBO単体からどれだけ改善・悪化したか」

を測る。


# 16. 帰無データを最初に使う

MR脚の検証では、実データに行く前に同じ箱形成ロジックを、

- GBM
- ボラティリティクラスタリングを持つ系列
- 必要ならジャンプを含む系列

へ適用する。

また実価格の日次リターンの方向だけをランダム化し、ボラティリティ構造をある程度保存した疑似系列を作る方法も使える。

帰無系列で、

\[
E[PnL_{MR}]
\approx 0
\]

となることを確認する。

もし帰無系列でもMRが有意に儲かるなら、

- ルックアヘッド
- ボックス確定の事後利用
- 形成期間を使った選択バイアス
- TP/SL約定順序

などの実装上の問題を疑う。

さらに逆に、

- 箱内OU
- ブレイク後ドリフト

という人工的に仮説を埋め込んだ系列でもテストし、本当に存在するエッジを戦略が検出できるか確認する。


# 17. As-ofルール

最終的に確定した箱を過去にさかのぼって使ってはいけない。

各Boxオブジェクトには少なくとも、

- `h_fixed_at`
- `l_fixed_at`
- `confirmed_at`
- `ended_at`

を保持する。

MR分析に使えるのは、

\[
t\ge confirmed\_at
\]

のデータのみ。

形成期間を、後から確定した上下限で再評価すると、ボックス内で平均回帰しているように機械的に見えてしまう。


# 18. 日足バックテストの約定上の注意

日足では、同じ日にTPとSLの両方へ到達した場合、どちらが先だったか分からない。

下位足を使えない場合は、

> SLが先に成立した

という保守的な仮定を使用する。

また、

- 当日高値から計算したトレーリングストップを、その高値より前の値動きに適用しない
- 終値判定ストップと場中逆指値を混同しない
- BO時は通常時より悪いスリッページも検証する

必要がある。


# 19. 日本株の場合

個別株を対象とするなら追加で、

- 上場廃止銘柄を含む
- 株式分割を適切に調整する
- 配当落ちによる見かけの下方ブレイクを処理する
- 空売り可能性、貸株料、逆日歩を反映する
- 値幅制限で実際には約定できないケースを処理する
- 決算前後のギャップリスクを別扱いする

必要がある。

特に価格水準そのものからボックスを作るため、境界検出用の価格系列とPnL計算用の価格系列の調整方法は事前に固定する。


# 20. ベンチマーク

複雑な状態機械に価値があるか確認するため、必ず単純戦略と比較する。

最低限、

1. Donchian Breakout
2. ATR Breakout
3. 単純なBollinger Mean Reversion
4. BOのみのイベント駆動ボックス
5. MRのみのイベント駆動ボックス
6. MR＋BO
7. 同じExit・SizingでEntryだけランダム化した戦略

を比較する。

複雑なBOXモデルが単純戦略をコスト後で明確に上回れないなら、複雑さに価値はない。


# 21. 検証順序

## Phase 0：仕様検証

- 完全な状態遷移表
- 合成価格パスで単体テスト
- As-ofチェック
- 帰無データでコスト前EV ≈ 0

ここを通過しない限りバックテスト成績は評価しない。


## Phase 1：BO単独

まずイベント駆動の箱形成そのものに価値があるかを見る。

比較：

\[
\text{Donchian BO}
\quad vs \quad
\text{Event-driven Box BO}
\]

これで勝てない場合、箱形成ロジック自体の価値は弱い。


## Phase 2：MR単独

実市場において、

\[
\hat p
>
p_0+\text{cost adjustment}
\]

が存在する領域を探す。

存在しなければMRは棄却する。


## Phase 3：統合

BO単独にMRを追加し、

\[
\Delta PnL
=
PnL_{MR+BO}
-
PnL_{BO}
\]

を評価する。

MR追加によって、

- リターン増加
- DD低下
- Sharpe改善
- Tail Risk改善

のいずれも確認できないなら、MRを無理に残さない。


## Phase 4：高度化

初めてここで、

- Box Score
- ハザードモデル
- 動的ウェイト
- タッチ回数
- 出来高
- リテスト
- 決算フィルター

などを1つずつ追加する。

追加条件は必ず、

\[
\text{Baseline}
\rightarrow
\text{Baseline + Feature}
\]

の差分で価値を判断する。


# 22. 過学習対策

自由パラメータは初期版でできるだけ少なくする。

少なくとも、

- \(k_{SL}\)
- \(k_{BO}\)
- \(k_{fail}\)
- 極値確定幅 \(m\)
- MRエントリー閾値
- TP
- タイムアウト
- 最小箱幅

などが候補になるため、すべてを最適化してはいけない。

多くは事前に固定し、探索するのは2〜3個程度に抑える。

評価では、

- walk-forward
- purged / combinatorial cross validation
- Deflated Sharpe Ratio
- PBO
- パラメータ±20%の感応度
- 開始日をずらした検証

を行う。

最高Sharpeの一点ではなく、**広いパラメータ範囲で安定していること**を重視する。


# 23. 最終的な戦略の最小形

最初に実装すべきバージョンは、以下まで単純化する。


## BOX

- 確定済みBOXのみ
- 箱幅がATR比で一定範囲
- 下端付近でMRロング
- 上端付近でMRショート
- TP / SL / Time Stopを明示
- 1箱1方向あたり再エントリー回数を制限


## MR終了

\[
C>H+k_{SL}ATR
\]

または、

\[
C<L-k_{SL}ATR
\]

でMRを終了。


## BO開始

さらに価格が進み、

\[
C>H+k_{BO}ATR
\]

または、

\[
C<L-k_{BO}ATR
\]

で初めてBOへ移行。


## BO

- 終値確認
- 翌寄り執行
- 旧BOXのMR停止
- 新しい極値形成を開始
- 失敗判定またはトレーリングで退出


## 新BOX

- 極値更新
- ATR幅の反転で片側確定
- 反対側も確定
- 必要な箱幅を満たせばBOX認定


# 24. 最重要の棄却条件

この戦略では、MRを残すこと自体を目的にしてはいけない。

最初に問うべきなのは、

\[
\boxed{
\text{箱内MRは、同じ箱アルゴリズムを帰無価格系列に適用した場合を超えるか？}
}
\]

である。

超えなければ、

\[
\boxed{
MR\text{を削除する}
}
\]

その場合、戦略は

\[
\boxed{
\text{イベント駆動型BOXによるBreakout Trend Following}
}
\]

へ縮小する。

一方でMRに独立した優位性があり、かつMRをBOに追加した箱ライフサイクル全体のネットPnLも改善するなら、初めて

\[
\boxed{
\text{BOX内Mean Reversion}
+
\text{Breakout Momentum}
}
\]

というハイブリッド戦略として成立する。

したがって検証上の最重要順序は、

\[
\boxed{
\text{帰無検証}
\rightarrow
\text{BO単独}
\rightarrow
\text{MR単独}
\rightarrow
\text{統合}
\rightarrow
\text{高度化}
}
\]

である。

この順序を守ることで、「箱らしいチャートを作れた」ことと「収益性のあるクオンツ戦略を作れた」ことを混同せずに済む。
