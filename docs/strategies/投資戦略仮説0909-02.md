# 5. Existing Momentum Baseline

Long側は、直前までの研究で使用したMomentum baselineをそのまま再利用する。

基本定義：

```math
ResidualReturn_{i,t}
=
rawReturn_{i,t}
-
beta_{i,t} \times topixReturn_t
```

直近1観測行をskipし、その前の60観測営業日のResidual Returnを合計する。

```math
M60_{i,t}
=
\sum_{k=1}^{60} ResidualReturn_{i,t-k}
```

過去実装と完全に同じ、

* 60観測行
* skip 1
* `min_periods=60`
* code再登場 / 長期gap時のreset
* 非有限値 / 履歴不足のneutral処理
* 当日cross-sectional percentile rank
* rank centering / scaling
* EWMA `alpha=0.25`
* `adjust=False`

を使用する。

既存baselineとの予測値がbitwise一致することを最初に確認する。

今回、Momentum horizonやEWMA alphaを再探索しない。

# 8. Score Stitching

最終的には公式採点コードへ1本のscoreを渡す必要がある。

そのため、Long / Neutral / Shortの独立ランキングを1本の連続scoreへdeterministicにstitchする。

必須条件：

```text
Q1/Q2候補のscore < Q3候補のscore < Q4/Q5候補のscore
```

となるようにbandを分離する。

例えば概念的には、

```text
Short band  : 0.0 ～ 0.4
Neutral band: 0.4 ～ 0.6
Long band   : 0.6 ～ 1.0
```

のようにする。

ただし公式のrank / quintile実装を確認し、**実際に公式Q1～Q5が意図したmembershipと一致する方法**を実装すること。

浮動小数点tieに依存しない。

必要なら全銘柄に一意なordinal scoreを付ける。
