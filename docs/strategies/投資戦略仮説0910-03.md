# 1. 研究目的

西部証券「日度量价因子的统一线性框架」で報告された、

```text
DTI = Daily Turnover Information
```

の考え方をStock Competition 2026へ適応する。

DTIの基本思想は、

> 過去1か月の日次換手率を平均値など1つの統計量へ圧縮せず、
> 日次系列そのものと、値の大小順に並べた系列の双方を線形モデルへ入力して、
> 将来リターンを予測する

ことである。

今回は、

```text
High DTI score -> Long
Low DTI score  -> Short
```

として、Long / Shortの両側をDTIだけで構築した場合の性能を検証する。

# 74. 最終原則

今回の目的は、

> Train上で最も高いSharpeを出すDTI設定を探すこと

ではない。

目的は、

> **西部証券が報告した「日次換手率の完全な系列と順序統計には、単純な平均換手率以上の情報がある」というDTI仮説を、日本株の1日先market-adjusted returnへ適応した場合にも再現できるかを、有限かつ因果的なTrain-only実験で検証すること**

である。

さらに前回DRIの教訓から、

```text
model coefficients
prediction dispersion
Long leg
Short leg
turnover
cost
```

を必ず分解する。

総合Net Sharpeだけで結論を出してはいけない。
