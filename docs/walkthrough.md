# 高値近接度ファクターによるモメンタム戦略高度化 検証結果

## 重要な追補（2026-09-24）

初回比較のC3は、現在では採用候補として扱いません。特徴量`Close_t / rolling_max(High, 250)`がraw価格の単位変化をまたいでおり、`AdjustmentFactor`イベントを近接度へ反映していませんでした。Train監査では、2011〜2014年の有効な近接度行の3.84%で250行窓に係数イベントが含まれ、例としてコード16050は2013-09-26の近接度が0.002129、その翌日も0.002142になっていました。詳細は[correctness audit](../reports/DM-20260924-01/TECHNICAL_AUDIT.md)を参照してください。

定義上の修正版`C3S`は別候補として固定し、凍結リリース`DM-20260924-C3S-v1`を作成しました。raw `High`/`Close`を当日までのAdjustmentFactorイベント累積で同じ価格単位へそろえ、250個の有効観測がある場合だけ52週近接度を計算します。Train-only比較では2011〜2014年のNet SharpeがH0の0.4051に対して0.6567、差+0.2516、改善3/4 foldでした。ただし、この期間は既知で、未調整bootstrap 95%区間`[-0.1076, +0.6278]`はゼロをまたぎます。これは探索的な記述値で、凍結は比較の再現性確保であり、採用判断ではありません。

日次PnL分解ではC3Sの年率Gross P/LがH0比+1.04ポイント、コストが-0.28ポイント、Net P/Lが+1.32ポイントでした。最大DDはH0の-10.35%に対してC3Sが-11.25%と悪化しています。予測日・銘柄行・ラベルcoverageは一致しました。

同じValid期間は別リリースで既に評価されています。今回は固定したC3Sと、凍結版`DM-20260908-v1:M_res60s1_a0.25`を公式互換採点器で一度比較しました。Net SharpeはH0が-0.3899、C3Sが-0.2409（差+0.1490）でしたが、どちらもマイナスです。C3Sの年率Net P/Lは-1.39%、H0は-1.99%。Turnoverとコストは下がる一方、Gross側の改善は小さく、最大DDはわずかに悪化しました。

Valid期間のC3SをLong/Shortに分けると、Longは年率Net P/L **+0.64% / Net Sharpe +0.130**、Shortは **-2.02% / -0.372** でした。Shortの損失寄与がLongの利益を上回っています。これはsplit-safe修正版C3Sの内訳です。初回定義の旧C3はValid未評価です。既読データのため、比較もレッグ別成績も独立OOSや採用根拠とは扱いません。詳しい年別指標は[凍結リリースのValid評価記録](../releases/DM-20260924-C3S-v1/VALID_EVALUATION.md)、全データは[c3s_long_short.json](../reports/DM-20260924-01/c3s_long_short.json)にあります。現行の`submission.py`はC2を既定出力し、変更していません。

## 概要
従来の「60日残差モメンタム戦略（Champion: DM-20260908, `res60s1` + EWMA 0.25）」に対し、George & Hwang (2004) 等の学術研究で実証されている「高値近接度（High Proximity / 52-Week High Anomaly）」をクオンツファクターとして導入し、モメンタムの質の判定・複合ランキングによる高度化を検証しました。

[AGENTS.md](../AGENTS.md) に則り、完全Train-only（2011–2014年開発4 fold + 2015–2016-03確認期間）で因果性・Prefix-Invarianceテストを実施した上で、全7候補のウォークフォワード・バックテストを行いました。

## 初回C3の結果の解釈

以下は初回runで記録された集計値です。`prox250`がraw価格の単位変化をまたいでいたため、52週近接度の正しい経済効果を示す結果としては扱いません。低Turnoverと低コストは観測されましたが、元定義には分割由来の順位歪みが含まれます。修正版C3Sは別の実験・別の結果です。

1. **Grossとコストの両方がNet差に寄与**:
   - H0比の年率Gross P/L差は+0.28ポイント、コスト差は-0.28ポイント、Net P/L差は+0.56ポイントでした。寄与の精密なSharpe分解はできません。
2. **Fold結果は均一でない**:
   - 2011年はH0よりNet Sharpeが0.2377低く、2012〜2014年は上回りました。4 foldと未調整bootstrapだけで安定した優位を立証しません。
3. **2015〜2016-03は独立OOSではない**:
   - 同期間は以前の研究で参照済みです。元C3とH0のNet Sharpeはいずれも負でした。確認値として採否・持続性を主張しません。
